SPRCNHS Website
===============

A static school information website built with HTML, CSS, and vanilla JavaScript.

Project structure
------------------
- Main HTML files: site pages
- news/: individual news articles
- assets/images/: image assets used by the site
- assets/audio/: optional homepage background music
- css/style.css: shared site styles
- js/script.js: shared interactions

Local development
------------------
Open index.html in a browser or serve the project directory with a local static HTTP server. Relative paths are used for assets and page links. Keep filenames lowercase and use hyphens between words.

Deployment
----------
Deploy the repository root as the static publish directory; no build command is required.

Homepage background music
-------------------------
Add a licensed MP3 at `assets/audio/Bagong Pilipinas Hymn.mp3`. The homepage player does not autoplay and includes a control to start or stop playback.

Curriculum references
---------------------
Curriculum links on academics.html point to official Department of Education pages or the DepEd Learning Portal. They are national references and do not guarantee that every listed specialization is currently offered by SPRCNHS.
